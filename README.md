# Advanced Database Systems

University coursework from the **Advanced Database** module at HTWK Leipzig.

I took this module to deepen my practical understanding of databases beyond basic SQL. The repository contains selected exercises and implementations using Oracle Database, PL/SQL, Java database access, and object-relational mapping.

## Topics

The coursework covered:

- advanced SQL and PL/SQL
- object-relational features in Oracle
- user-defined types, inheritance, references, and sequences
- database access with JDBC
- prepared statements and result-set metadata
- persistence and object-relational mapping with JPA
- EclipseLink and Oracle database configuration

## Technologies

- Oracle Database
- SQL and PL/SQL
- Java
- JDBC
- JPA
- EclipseLink

## Notes

The repository contains selected coursework rather than every exercise from the module.

Some exercises build on earlier work and are therefore grouped together in the same project structure. Database connection settings refer to the original university environment and must be adjusted before running the code elsewhere.
